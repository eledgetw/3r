# 佛教宇宙觀 - 互動畫布 (Buddhist Cosmology Interactive Canvas)

這是一個以現代前端技術構建的**佛教宇宙觀（三界六道與四聖法界）**視覺化互動畫布。專案透過無限畫布縮放、古典泥金風格介面、多媒體動態節點與《俱舍論》計量換算，將深奧龐大的佛教時空結構直觀呈現。

---

## 🌟 核心特色

- **無限平移與自由縮放 (Pan & Zoom)**
  - 支援觸控板雙指手勢、滑鼠拖曳與滾輪縮放。
  - 支援遠距宏觀縮放，觸發「一微塵中見大千」的三千大千世界（華藏世界海）矩陣視角。

- **三界六道與四聖法界完整收錄**
  - **出三界**：四聖法界（佛、菩薩、緣覺、聲聞）與四大淨土體系。
  - **無色界**：空無邊處、識無邊處、無所有處、非想非非想處（有頂天）。
  - **色界**：初禪至四禪十八天（含五淨居天）。
  - **欲界**：六欲天（他化自在天、化樂天、兜率天、夜摩天、忉利天、四大天王天）。
  - **其餘五道**：人道（四大部洲）、阿修羅道（四大修羅王）、畜生道、餓鬼道、地獄道。

- **業因果報流轉動態可視化**
  - 點擊任意節點即可在 SVG 畫布上以動態光束呈現因果網絡：
    - 🟢 **綠色光束**：如何投生至此（因緣）
    - 🔴 **紅色光束**：福盡將往何處（果報）

- **九山八海與四大部洲深度展開**
  - 內建《俱舍論》記載之七金山、八海、大鐵圍山同心階梯山海數據與互動剖析。

- **《俱舍論》時空度量衡轉換器**
  - **空間換算**：由旬、俱盧舍、尋（弓）、肘、指節 ➔ 換算為公里數、地球赤道圈數與光速傳播時間。
  - **時間換算**：剎那、怛剎那、臘縛、牟呼栗多、天年、中劫、大劫 ➔ 換算為現代秒、分、小時與地球億年。

- **沉浸式視覺與音效**
  - MP4 動態透明圖層融合（`mix-blend-mode: screen`）。
  - 畫面中心追蹤技術，依視野焦點自動切換背景音訊與高亮導航。

## 🎮 操作指引

| 操作方式 | 功能說明 |
| :--- | :--- |
| **滑鼠左鍵拖曳 / 雙指滑動** | 平移畫布視角 |
| **Command (Ctrl) + 滾輪 / 雙指開合** | 放大 / 縮小畫布（縮小至極限進入大千世界模式） |
| **點擊左側導航列節點** | 快速平滑跳轉至該法界/天界 |
| **點擊畫面中的天界圖標/影片/標籤** | 展開右側結構化詳細資訊面板與因果流轉圖 |
| **點擊右下角「須彌山」按鈕** | 一鍵重置鏡頭回預設須彌山主視角 |
